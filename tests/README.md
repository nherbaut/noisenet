# Essais matériels

Créer un rapport dans le dossier concerné à partir de [_template.md](_template.md). Conserver les données brutes CSV avec le rapport ; nom conseillé : `AAAA-MM-JJ-NN-xxx-sujet.md`.

| Dossier | Vérifications attendues |
|---|---|
| `power/` | Consommation normale et émission, autonomie, recharge, passage solaire/batterie, protections de charge |
| `acoustics/` | Conversion ADC, comparaison au sonomètre, effet du montage, calibration |
| `radio/` | OTAA EU868, réception, décodage, séquences, veille entre transmissions |
| `outdoor/` | Montage contre la pluie, condensation, température, fixation, réception sur site |

Définir les critères d'acceptation avant chaque essai. Les objectifs d'autonomie et de précision restent à fixer et à vérifier expérimentalement.
