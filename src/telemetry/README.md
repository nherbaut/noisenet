# Agrégation et télémétrie

Futurs fichiers : `telemetry.c` et `telemetry.h`. Point de départ : agrégation une minute et transmission de plusieurs résumés environ toutes les cinq minutes. Définir format binaire, unités, ordre des octets, version, statut et séquence avec le décodeur serveur.

Ne pas qualifier les indicateurs de mesures normatives sans validation de la chaîne complète.
